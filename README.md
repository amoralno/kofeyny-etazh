# Кофейный этаж

Мобильная версия демонстрационного магазина на HTML, CSS и JavaScript.

## Файлы
- `index.html` — разметка
- `style.css` — оформление и адаптивная мобильная версия
- `script.js` — каталог, фильтры, сортировка и корзина
- `images/` — фотографии товаров и фоновое изображение

## Публикация на GitHub Pages
1. Создайте публичный репозиторий `kofeyny-etazh`.
2. Загрузите содержимое этой папки в корень репозитория (не сам ZIP-файл).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main`, папку `/ (root)` и нажмите Save.
6. После публикации сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/kofeyny-etazh/`.

Открывать опубликованный сайт лучше в Safari/Chrome. Не переносите `index.html` отдельно от `style.css`, `script.js` и папки `images`.
